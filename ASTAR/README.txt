NHOM 03 | A* SEARCH
========================================

MUC TIEU
- Cai dat thuat toan A* va hien thi cac buoc tim kiem.
- Trang thai dau: A | Trang thai dich: B.

CAU TRUC
- CPP/  : ma nguon C++, input, output va file chay.
- HTML/ : giao dien truc quan tren trinh duyet va input mau.

CHAY C++ (Windows)
1. Mo thu muc CPP.
2. Chay RUN_ASTAR.bat. May can co Dev-C++/MinGW GCC.
3. Ket qua duoc ghi vao output.txt.

CHAY HTML
1. Mo HTML/astar.html bang Chrome hoac Edge.
2. Bam Import input.txt de nap HTML/input.txt neu can.
3. Su dung cac nut dieu khien de xem cac buoc A*.

DINH DANG INPUT
A(14): D(7), E(13), F(20)
TTD: A
TTKT: B
- So trong ngoac o ten nut la heuristic h(n).
- So trong ngoac o nut ke la chi phi canh.
- A* su dung f(n) = g(n) + h(n).
