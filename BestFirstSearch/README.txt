NHOM 03 | BEST FIRST SEARCH
========================================

MUC TIEU
- Cai dat Best First Search theo de bai.
- Nhom 03 la nhom le, vi vay su dung Best First Search.
- Trang thai dau: A | Trang thai dich: B.

CAU TRUC
- CPP/  : ma nguon C++, input, output va file chay.
- HTML/ : giao dien truc quan chay tren trinh duyet va input mau.

CHAY C++ (Windows)
1. Mo thu muc CPP.
2. Chay RUN_BEST_FIRST.bat. May can co Dev-C++/MinGW GCC.
3. Ket qua duoc ghi vao output.txt.

CHAY HTML
1. Mo HTML/best_first.html bang Chrome hoac Edge.
2. Bam Import input.txt de nap HTML/input.txt neu can.
3. Bam nut nap/chay va su dung cac nut dieu khien tren giao dien.

DINH DANG INPUT
- Dong do thi: A(20): C, D, E
- TTD: A
- TTKT: B
- So trong ngoac la heuristic h(n); Best First Search uu tien nut co h nho nhat.
