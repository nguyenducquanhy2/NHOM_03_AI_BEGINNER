NHOM 03 | BREADTH-FIRST SEARCH (BFS)
========================================

MUC TIEU
- Mo phong thuat toan tim kiem theo chieu rong (BFS).
- Trang thai dau: A | Trang thai dich: G.

CAU TRUC
- CPP/  : ma nguon C++, input, output va cac script chay.
- HTML/ : giao dien truc quan, input mau va huong dan HTML.

CHAY C++ (Windows)
1. Mo thu muc CPP.
2. Chay RUN_NHOM03_CMD.bat. Script thu tim g++ trong PATH va cac vi tri Dev-C++ pho bien.
3. Ket qua duoc ghi vao output.txt.

CHAY C++ (macOS/Linux)
- Mo Terminal tai thu muc CPP, chay: chmod +x RUN_NHOM03_MAC.sh && ./RUN_NHOM03_MAC.sh
- Hoac bien dich: g++ -std=c++11 bfs.cpp -o bfs && ./bfs input.txt output.txt

CHAY HTML
1. Mo HTML/visualizer.html bang Chrome, Edge hoac Safari.
2. Bam Import input.txt va chon HTML/input.txt neu muon nap lai du lieu mau.
3. Bam Ap dung input & ve lai, sau do Bat dau/Buoc tiep/Chay tu dong.

DINH DANG INPUT
A: B, C, D
B: I, G
C: E, F
D: C, F
E: G, K
F: K
I: G
TTD: A;
TTKT: G
