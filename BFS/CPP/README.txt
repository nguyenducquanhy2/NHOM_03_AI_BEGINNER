NHOM 03 | BFS - CPP
========================================

FILE
- bfs.cpp : ma nguon BFS.
- input.txt : do thi va trang thai dau/dich.
- output.txt : bang cac buoc va duong di sau khi chay.
- RUN_NHOM03_CMD.bat : script Windows.
- RUN_NHOM03_MAC.sh : script macOS/Linux.
- Makefile : tuy chon bien dich bang make.

WINDOWS
Chay RUN_NHOM03_CMD.bat. Script se thu tim g++ trong PATH va cac vi tri cai dat Dev-C++ pho bien.

MACOS/LINUX
  chmod +x RUN_NHOM03_MAC.sh
  ./RUN_NHOM03_MAC.sh

Hoac bien dich thu cong:
  g++ -std=c++11 bfs.cpp -o bfs
  ./bfs input.txt output.txt

Dieu khien giao dien CMD: ENTER = buoc tiep; A = chay den cuoi; R = reset; Q = thoat.
